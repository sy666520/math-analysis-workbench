# 分析工作台 · Mathematical Analysis Workbench

《工科数学分析》数智实践大作业 · **选题 C4 数学分析学习工作台**

**在线访问：<https://sy666520.github.io/math-analysis-workbench/>**（也可下载本仓库后双击 `index.html` 离线运行）

一个不需要联网、不需要安装、双击即用的数学分析学习环境：把「知识导航」「函数实验」「定理检验」「错题复盘」「可追溯的 AI 助教」整合在同一个界面里。

---

## 一、怎么打开

直接用浏览器打开 `index.html` 即可。

```
双击 index.html
```

- 推荐 Chrome / Edge（其余现代浏览器亦可）
- 全部资源都在本地：KaTeX 公式渲染器已随包内置于 `assets/vendor/katex/`
- **完全离线可用**：断网状态下所有功能（含 AI 助教）正常
- 数据保存在浏览器 localStorage 中，不上传、不联网

## 二、五个模块

| 键 | 模块 | 一句话 |
|---|---|---|
| `1` | 知识图谱 | 39 张知识卡片按 8 章排布，箭头是前置依赖，点开看定义 / 条件 / 易错点 / 反例 |
| `2` | 函数实验室 | 输入任意函数，滑参数看极限、导数、积分行为，附左右逼近表 |
| `3` | 定理检验 | 数值检验中值定理的每一条前提，并定位 ξ；条件不满足时也能说清"为什么" |
| `4` | 错题本 | 只记"错在哪一步"，按 1/2/4/7/15 天间隔排入复习队列 |
| `5` | AI 助教 | 在知识卡片里检索并组织答案，说明命中来源，可导出对话记录 |

数字键 `1`–`5` 可快速切换模块。

## 四、技术选择

**不引入任何框架、不打包、不联网。** 原因是任务书要求网页"含 index.html 的文件夹（可离线打开）"，而任何 CDN 依赖都会在答辩现场的断网环境下失效。所有代码是原生 ES5/ES6 + Canvas 2D + SVG，约 3200 行，无构建步骤。

公式排版是唯一的外部件——KaTeX，因为它**离线可用且可嵌入字体**，自己手写公式排版质量达不到教材水准。

## 五、数据说明

- 知识卡片、错题、助教配置、聊天记录全部存在 `localStorage`，键名以 `ab.` 开头
- 换电脑或清理浏览器数据会丢失记录，重要记录请用「导出 Markdown」「导出对话记录」保存
- 若浏览器禁用了 localStorage（极少数隐私模式），应用会自动降级为内存模式，功能不受影响但关闭后不保留

## 六、已知边界

- 定理检验的判定是**数值经验证据**，不是证明。界面里对此有明确标注
- 表达式支持一元函数；多元图形不在本工具范围内
- 数值积分在含真奇点处会返回"未定义"，这是有意为之，避免给出错误数值

更完整的设计说明见 `docs/设计文档.md`。
